# Sudoku Game

## Описание
Классическая игра Судоку с графическим интерфейсом на Windows Forms.

## Возможности
- Рандомная генерация поля
- Три уровня сложности (Easy/Medium/Hard)
- Сохранение и загрузка игры
- Подсветка строк, столбцов и квадратов 3x3
- Подсветка одинаковых цифр
- Валидация ходов (ошибки красным)
